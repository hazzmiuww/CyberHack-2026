# Public assets

Drop the Kenang logo here as **`kenang-logo.png`**.

The dashboard header (`app/qc-dashboard/KenangLogo.tsx`) loads `/kenang-logo.png`.
If the file is missing, it falls back to a text wordmark automatically.

> Tip: a transparent-background PNG looks best on the dashboard's light header.
> The logo image your team designed has a black background — export it with a
> transparent background (or crop tightly) before saving it here.
